# Лендинг-приглашение на день рождения

React + Supabase лендинг с подтверждением участия.

## Что делает

- Открывает приглашение по ссылке вида `?invite=<token>`.
- При первом открытии активирует таймер и ставит срок действия +48 часов.
- Сохраняет ответ гостя (`Да, я приду` / `Не смогу`) и имя.
- Telegram-ссылка показывается только если гость нажал `Да, я приду`.

## Быстрый старт

1. Установить зависимости:

```bash
npm install
```

2. Создать `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

3. В Supabase SQL Editor выполнить `supabase/schema.sql`.

4. Запустить локально:

```bash
npm run dev
```

## Как выдавать персональные ссылки

1. Сгенерируйте токен (пример: `maksat-guest-001` или UUID).
2. Добавьте запись в таблицу `invites`:

```sql
insert into public.invites (token) values ('maksat-guest-001');
```

3. Отправьте гостю ссылку:

```text
https://ваш-домен/?invite=maksat-guest-001
```

Срок начнет отсчитываться с первого открытия ссылки гостем.
