# Лендинг-приглашение на день рождения

React + Supabase лендинг с подтверждением участия.

## Что делает

- Открывает приглашение по ссылке вида `?invite=<token>`.
- Если `invite` в URL отсутствует, создает его автоматически.
- Ответы принимаются до фиксированного дедлайна: `29 июля 2026, 13:00` (Астана).
- Сохраняет ответ гостя (`Да, я приду` / `Не смогу`) и имя.
- Telegram-ссылка показывается только если гость нажал `Да, я приду`.
- После дедлайна фиксируется автоматический отказ, ответить позже уже нельзя.
- Фото домика берутся из локальных файлов и их пути хранятся в таблице `event_content`.

## Быстрый старт

1. Установить зависимости:

```bash
npm install
```

2. Создать `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

3. В Supabase SQL Editor выполнить `supabase/schema.sql` (создаст/обновит таблицы и заполнит `event_content`).

4. Запустить локально:

```bash
npm run dev
```

## Как отправлять ссылку

```text
https://ваш-домен/
```

При первом открытии ссылка автоматически получит `?invite=...`, а проверка дедлайна будет общей для всех.
